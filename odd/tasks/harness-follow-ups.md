## Specs

- **S1 — secret-guard apostrophe bypass.** On main, `bash <<'EOF'` / `echo it's ok` / `cat .env` / `EOF` is allowed: the apostrophe in the body opens a quote in `splitCommands` (`secret-guard.mjs:122-127`) that swallows the following lines, so `cat .env` is never checked. Fix so that a protected path on any line hidden by a quote that spans a newline is still checked. Assumption: the fix only adds denies (fail closed); it never turns a main deny into an allow. Every new deny shape is pinned in `tests/guard/differential-corpus.mjs` as a named difference from main, with the reason. The heredoc-as-data relaxation stays out of scope: main's heredoc behavior and the Write-tool workaround stay as decided in `principal-engineer-style.md` L29-L30.
- **S2 — Writers avoid the guard's known false positive.** The subagent contract (`hooks/contract/subagent.md`) tells writers to create or edit files whose text names a protected path (secrets directory, `.env`, `*.pem`/`*.key`) with the Write or Edit tool, never a Bash heredoc or `echo` redirect, matching the README workaround.
- **S3 — Stop gates wait for running subagents.** While background subagents may still be writing, the Risk-line gate (`risk-line.mjs`) and the review gate (`review-gate.mjs`) re-block every waiting turn, because each byte a writer changes is a new target. A per-session counter of open subagents, incremented on SubagentStart and decremented on SubagentStop, keeps both gates silent while it is above zero. Assumptions: an idle-age bound (like `OPEN_LINEAGE_MAX_IDLE_MS`) expires a count left open by a crashed agent; the counter fails open to today's behavior (missing or unreadable state → the gates run as now); the check still runs at the first Stop after the writers finish; existing pinned behaviors (`tests/gate/gate.test.mjs:142`, `:157`; `tests/risk-line/risk-line.test.mjs:146`, `:152`) stay. The doc conflict "the gate does not remind again in the same session" (`rdd-review/SKILL.md:38`) is corrected to the per-target behavior (owned by T4).
- **S4 — Security checklist reaches the risk lens.** `odd-review context` for the `review-risk` lens includes `skills/rdd-review/references/security-checklist.md` inside the context block, before `ODD_REVIEW_CONTEXT_END` (`lib/review/evidence.mjs` `buildContext`), counted against the context budget. Assumption: not bound into the subject hash (static plugin text; the trees already bind the candidate). `agents/review-risk.md`, `rdd-review/SKILL.md`, and README stop saying the checklist does not reach the agent.
- **S5 — `hot_path` ignores Markdown file names.** A token such as `security` or `auth` in the name of a Markdown/prose file (`.md`, `.mdx`, `.txt`, `.rst`) no longer raises `hot_path`. Assumption: prose content changes stay assessed as today (passive or medium by the other rules).
- **S6 — `verifier_weakening` precision.** (a) A marker inside a string literal on the same line (`'...// @ts-ignore...'`, `"it.skip( is detected"`) does not count; (b) `{ skip: N }` with a number (Prisma `findMany({ skip: 10 })`) does not count, while `{ skip: true }` and `{ skip: 'reason' }` still do. Existing positives stay green; `tests/assess/fixtures.mjs` itself is no longer flagged when it only adds quoted markers.
- **S8 — Writers never rewrite files they do not own.** Source: observed defect during this feature (L5): two parallel workers proved RED with `git stash` on the shared working tree. The subagent contract forbids `git stash`, `git checkout -- <path>`, and other tree-rewriting commands for writers; RED is proven by running the new test before the fix. Confirmed by the user (L10).
- **S7 — Run the debugging evals.** `scripts/eval.sh --case debugging-fires` and `--case debugging-stays-quiet`; record pass rates and cost. Fix graders or cases only when a failure is in the eval, not the skill.
