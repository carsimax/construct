# Panel clean-room rewrite

Objective: rewrite the status panel (`plugins/construct/hooks/panel/`) as Construct's own code, written from this behavioral spec and the existing tests without reading the current or upstream panel code, so the claude-flightdeck attribution (and, since `state.js` is rewritten whole, the gentle-agent-state one) can be removed. Branch: one per task, `feat/panel-clean-room-<n>-<slice>`. Baseline: 5d2e9ce. Delivery strategy: ask-on-risk; chains: stacked-to-main. Slices: PR #54 = T1 (c19feda..9669a70); PR 2 = T2 + T4 on `feat/panel-clean-room-2-layout`, stacked on T1. Test runner: `claude plugin test plugins/construct` and `node --test tests/` (3 mod tests fail on clean HEAD from an AskUserQuestion permission denial; memory #9).

## Clean-room rule (every writer task)

The writer never reads `plugins/construct/hooks/panel/draw.js`, `layout.js`, or `state.js` at any revision (no Read, cat, `git show`, `git log -p`, or blame on them), nor the upstream claude-flightdeck or gentle-agent-state sources. It deletes the old file with `git rm` before writing the new one. It may read: this document, the panel tests in `plugins/construct/tests/`, `hooks/register.js`, `hooks/routing.js`, `hooks/status/*`, `hooks/scripts/roles.mjs`, and the Claude Code mods reference. The tests are Construct's own and are the oracle; a test that pins an internal detail may change only when this document's spec allows it, and never to turn a check green otherwise.

## Specs

- **S1 — Panel is Construct's own code.** "me gustaria que atacamos la parte del sidepanel, reconstruirlo a nuestra manera para quitar claude-flightdeck". Assumption: "a nuestra manera" means our own code and structure; the observable panel (cards, rows, wording, colors) stays as it is today, so the existing tests are the verifier. A visual redesign is out of scope unless the user asks; S7 (L8) is that ask, and S7 overrides S5 where they differ.
- **S2 — Public surface unchanged.** Same exports and signatures, so `hooks/register.js` and the tests keep working:
  - `draw.js`: `PALETTE`, `fmtResetIn(resetsAt, nowMs)`, `gauge(pct, width) -> {on, off}`, `effortMeter(effort) -> {on, off}` (four slots), `CHANGES_FRAME_ROWS = 3`, `MAX_CHANGE_ROWS = 10`, `changeRows(bodyRows, used)` (-1 = card does not fit), `stackBar(counts[], width) -> number[]` (largest-remainder split), `panelBox`, `card({title, status, color, children, width, dim, marginTop})`; elements are `{type, props, children}`.
  - `layout.js`: `PANEL_COLUMNS = 66`, `clock(ms)`, `prettyModel(model)`, `buildPanel({panel, usage, odd, memory, nowMs, columns, rows, model, effort, git, changes})`.
  - `state.js`: `SCHEMA_VERSION = 3`, `initialState`, `merge`, `maskSecrets`, `filePathOf`, `isOutsideTasks`, `bucketOf`, reducers `onMainStep`, `onPermissionMode`, `onAgentSpawn`, `onTurnStep`, `onTurnStart`, `onTurnComplete`, `onToolCall`, `onToolSettle`, `onToolCheck`, `onCompact`, `onBlocked`, `onUnblocked`, selectors `mainBusy`, `isBlockingTool`, `agentsView(state, nowMs, max = 3)`, `shortName`, `phaseOf`.
  - Panel code may import `status/format.js` (`text`, `isNum`), `routing.js` (`roleFor`), `scripts/roles.mjs` (`kindOf`).
- **S3 — Persisted state v3 unchanged.** Atom `construct.panel.v3`. Shape: `v`; `agents[]` (max 20, oldest dropped; `id, role, type, description, model, effort, ctx, steps, startedMs, endedMs, status`); `inline {count, last}`; `gate {cells[] (max 60, oldest dropped), counts, denied, lastDenied, verdicts, buckets {file, shell, other}, pending {callId: bucket} (max 100)}`; `turn {turnId} | null`; `compactions`; `main {steps, model, effort, mode}`; `blocked`. `merge`: accepts v1-v3, anything else gives full defaults; a section of the wrong type gives that section's defaults; objects shallow-merge over defaults; legacy `receipt` and v2 `log` are dropped; totals are never capped.
- **S4 — State transitions.**
  - `onMainStep`: main steps +1, latest model and effort. `onTurnStep` (subagent): steps +1, `ctx` = input + cache-read + cache-creation tokens.
  - `onAgentSpawn`: adds a running agent (cap 20). A main-thread spawn carrying a permission mode also sets `main.mode` (`onPermissionMode`).
  - `onTurnStart` / `onTurnComplete`: main sets `turn` to `{turnId}` / back to null (not when the turn id differs); a subagent goes running / done with an end time.
  - `onToolCheck`: adds a cell, updates verdicts and buckets (`bucketOf`), records pending asks by call id, records last denied on deny. A re-check of a call id that is still pending is the same ask and counts once (L3).
  - `onToolSettle`: with a call id, the ask moves only if that id is pending (`cleared` if the call ran, `deny` if not); with no call id, the first pending ask of the tool's bucket moves.
  - `onToolCall`: a main-thread write outside `odd/tasks/` (`filePathOf`, `isOutsideTasks`) counts as inline. `onCompact`: compactions +1.
  - Blocked: `isBlockingTool` is true for AskUserQuestion and ExitPlanMode. `onBlocked` / `onUnblocked` set and clear the flag and return the same object when nothing changes. The wiring in `register.js` (unchanged) decides when they fire.
  - `maskSecrets` masks secrets in shown text (L4-L7), never weaker than baseline: the value of any `NAME=value`, `NAME: value`, or `--name=value` whose name contains, anywhere and in any case, `key`, `secret`, `password`, `passwd`, `pwd`, `token`, or `credential` (`PGPASSWORD`, `dbPassword`, `keyStorePassword`, `SECRET_KEY_BASE`, `SECRETS`, `KEY_FILE`, `MAX_TOKENS` too: false positives are accepted), with or without `export`, a quoted value masked whole; such a pair is found anywhere in the text, including nested in another flag's value or after a short flag (`--from-literal=password=abc`, `-Dpassword=abc`, `--set a.postgresPassword=abc`); `Authorization: Bearer|Basic <token>` of any length; URL passwords (`https://u:***@host`); `mysql -p<pw>` including a quoted password, whole; provider-style tokens: a lowercase prefix ending in `_` or `-` (`sk-`, `pk-`, `rk_`, `ghp_`, `gho_`, `ghs_`, `ghu_`, `ghr_`, `npm_`, `whsec_`, `xoxb-`, `glpat-`) or `SG.` followed by 16+ letters and digits (`.` allowed for `SG.`), so `npm_config_cache=/x` stays as is; runs of 32+ characters from letters, digits, `+`, `_`, `-` that contain a digit, with up to two trailing `=` (L9: API keys like `AIzaSyD-9tSrke72PouQMnMX-a7eZSW0jkFMBWY` and base64url JWT parts; UUIDs get masked too, accepted); an unquoted value runs to whitespace, `&`, or a quote, and a `?` inside it does not end it (`DB_PASSWORD=p?ss123` masks whole). The masked value reads `***`.
  - Last-denied detail (L4): the first present of `command`, `file_path`, `notebook_path`, `path`, `url`, `pattern` from the call input, masked, cut to 80 characters with `...` marking the cut; a deny with no tool name records the tool as `tool`.
  - `bucketOf`: Read, Glob, Grep, Write, Edit, MultiEdit, NotebookEdit are `file` (as baseline); Bash is `shell`; the rest `other`. The inline-write rule uses only the write tools.
  - `agentsView(state, nowMs, max)`: every running agent, then finished agents by most recent end time, up to `max` cards (L4).
  - Spawn with an id already present replaces that agent's card (no duplicate). A spawn with no subagent type is named `agent`. `shortName` drops a `construct:` prefix and turns underscores into dashes (`my_agent` → `my-agent`, `construct:unknown_x` → `unknown-x`).
  - Main turn: `onTurnComplete` clears an open main turn when the ids match or either id is missing. A main step is any step whose `agentId` is null or undefined; an empty effort is stored as `null`.
  - `merge` repairs nested shapes too (L4): a non-object agent entry is dropped, a missing bucket gets its defaults, a non-array `cells` becomes `[]`, and non-numeric totals in `counts` and `verdicts` become 0, so no reducer or selector throws on stored state. Robustness (L9): counts never go below 0; `agentsView` skips non-object entries; with no cwd, an absolute path with an `odd/tasks` segment pair counts as inside tasks.
  - `phaseOf` / `shortName` give an agent's panel phase and short name via `kindOf`; `mainBusy` is true while a main turn is open.
- **S5 — Rendered panel.** One column, width `max(40, floor(bodyColumns))`, 66 when unknown; root pane `minHeight` = body rows; every card full width with a round border, bold title left, status right; no header or legend; single-line rows clipped with `…`; empty cards omitted, main card always shown. Cards top to bottom:
  1. Main: title = prettified model (`Claude` when unknown); status `◆ blocked` amber when blocked, else `● <phase or busy>` while a main turn is open, else `○ idle` dim. Rows: `⎇ <branch>` when known; effort meter, effort word or `—`, `mode <mode>` when known, `N req`; context (only when a percent is known): 10-cell gauge, bold percent, `used/window` in k/M, `⟲N` amber when compactions > 0; limits `5h` and `7d`, each a 5-cell gauge, percent, `↻<time left>` when the reset is in the future; gauges use the warn color at 80% and above.
  2. ODD (only with a feature): title `ODD · <feature>` clipped, status `N open` dim; row `T<id>  <title>`; checkpoints `●` done, `◆` first open (bold), `○` others, joined by `━`, keeping the latest with a leading `…` when too many.
  3. GATE (only with checks or inline writes): title `GATE · permissions`, status `N checks`; `no checks yet` when none, else a `█` stacked bar allowed, cleared, pending, denied (each non-zero segment at least one cell); legend allowed, cleared (`classifier` in auto mode, else `you`), pending (hidden at zero), denied; bucket row `f: file n  s: shell n  o: other n` (dim at zero); `✗ tool: detail` masked, at most 80 chars; `⚠ N inline write(s) · <last two path parts>` in warn.
  4. MEMORY (memory data not null): title `MEMORY`, status `N memories` (permission color; `0 memories` dim with body `no memories yet`); off: no status, one line with the reason, amber for newer-schema or unwritable-database errors; counts `X to review · Y pinned · Z pending` (X amber above 0); `last save <age> ago · +N this session` when known.
  5. Agents (hidden with none): title `agents`, status `R running · T total`; up to six rows by start time, `+N earlier` when cut; row: `◐` running (suggestion color) or `✓` done (success), name padded to the longest (max 18), dim prettified model or `—`, effort meter, elapsed clock (running: now − start; done: end − start). No `failed` mark (unreachable today; dropped).
  6. Changes: title = branch or `changes`, status `↑N ↓N` non-zero parts only; hidden with no files and branch in sync; rows by lines changed, largest first; path `…/dir/name`; stat `+a -d` (success/error), `bin`, `+a` untracked with count, `new` untracked without; row budget = leftover body rows, at most 10, last row `+N more` when cut, title only at budget 0, card dropped below 0.
  - Formats: clock `m:ss`, `XhYY` from an hour; reset `25m`, `3h10m`, `4d2h`, `""` when unknown or past; tokens `666k`, `1.0M`, integers below 1000; gauge filled cells `round(pct × width / 100)` clamped, `▰` on, `▱` off; models `claude-opus-5-5` → `Opus 5.5`, `opus[1m]` → `Opus`, `claude-opus-4-1-20250805` → `Opus 4.1`, empty or non-string → `Claude`.
  - Palette roles → theme keys: main `claude`, agent `suggestion`, gate `success`, cleared `permission`, odd `merged`, git `remember`, amber `warning`, warn `error`, dim `inactive`, faint `subtle`.
- **S6 — Attribution removed.** No file carries the claude-flightdeck or gentle-agent-state MIT header or `adapted from` line; `LICENSE-flightdeck` and `LICENSE-gentle-agent-state` are deleted; NOTICE lists only gentle-shell; claude-flightdeck moves to the README's ideas-only credits (the card-panel idea came from it); `tests/panel-license.test.mjs` and `tests/skills.test.mjs` assert the new state (no header in the panel files, the two LICENSE files absent); README and CONTRIBUTING references and the `flightdeck` wording in panel test titles and fixtures are updated. Assumption: removing gentle-agent-state follows from rewriting `state.js` whole.

- **S7 — Panel personality: voice and glyphs.** "Aprovecha para darle mas personalidad al panel"; the user chose "Voz + glifos" (same card structure, a glyph and verb per agent role, statuses with voice, empty states with character, no emoji). UI text stays English. Assumptions marked (A):
  - Agent rows: role glyph, name, verb, dim model, effort meter, clock. Glyphs (A): explorer `⌕`, worker `⚒`, verifier `⊨`, general `◇`, judge-a/judge-b `⚖`, review-* `◎`, other `•`. Verbs running/done (A): explorer mapping/mapped, worker building/built, verifier verifying/verified, judge judging/judged, review reviewing/reviewed, general and other working/done. Running rows use the role's agent color; done rows dim with the success-colored glyph. All glyphs single-width. When a row does not fit, the model column goes first and the clock stays visible (L12).
  - Agents card status: `N at work · T` (was `R running · T total`); `all done · T` when none run.
  - Main card: branch, effort, and request count share one row: `⎇ <branch> · <meter> <effort> · N req` (mode appended as `· <mode>` when known). Status: `● <phase verb>` while a main turn is open (phase from `phaseOf`, e.g. `building`), `◆ waiting on you` (amber) when blocked, `○ ready` (dim) when idle.
  - GATE card: status `all clear` when nothing is pending or denied, `N waiting on you` when asks are pending, else `N checks`; with no checks the body reads `nothing waiting on you`.
  - Empty and quiet states (A): MEMORY with zero memories `nothing remembered yet`; changes card in sync with no files stays hidden.
  - Tests in `panel-layout.test.ts` and `panel.test.ts` that pin the old wording change to S7's wording in T2; nothing else in them changes.
